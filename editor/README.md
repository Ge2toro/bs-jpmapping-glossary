# 用語集エディター

リポジトリ直下の `start_editor.bat` をダブルクリックすると、http://127.0.0.1:8780/ が開きます。Python 3.8以上で動作し、Officeは不要です。終了時は起動用ウィンドウでCtrl+Cを押してください。

## 編集から公開まで

1. 「編集画面」で原案の個別編集／表形式を選びます。同じ原稿を編集し、切り替える前に保存します。文字サイズも共通です。
2. 編集内容は `editor/data/store.json` に自動保存されます。Ctrl+Sでも保存できます。**エディターの原稿そのものが下書き**です。用語ごとに採用・有効化する操作はありません。
3. 「サイト用に出力」または `run_make.bat` で、**新規項目を含む現在の編集原稿すべて**を `docs/index.md` へ出力します。参照画像も `docs/images/` へコピーします。既存の `_template.md`、テーマ、リンク集、GitHub Actionsは引き続き使います。
4. 「MkDocsプレビュー」を押すと、このPC内で `mkdocs serve` が起動し、**出力済みのサイトを新しいタブ**で開きます。このボタンだけでは原稿を出力しません。表示中に「サイト用に出力」し直すと、MkDocsが更新を検知してプレビューへ反映します。
5. 確認後のpush・デプロイは従来どおり自分で行います。

出力前の編集はサイトに反映されません。保存はエディター原稿への保存、出力はサイト用ファイルへの反映です。必須情報や画像に不足がある場合は該当用語と理由を表示し、出力を中止します。編集中の文章を保存することはできます。

「出力済み／前回出力から変更あり／未出力」は前回の出力内容との比較です。比較情報は `data/last-output.json` に記録します。この機能で初めて出力する前や、生成先Markdownを別途変更した場合は「出力履歴なし」と表示します。過去の採用情報は出力判定に使いません。

編集欄の横の小さいプレビューには、現在編集中の用語の文章・リンク・画像を表示します。入力に合わせて更新し、原稿の出力や採用操作は必要ありません。サイト全体の見た目の確認には「MkDocsプレビュー」を使います。

## MkDocsプレビュー

MkDocs、Materialテーマ、glightboxプラグインが必要です。既にサイトをビルドしているPythonを利用できます。現在のPythonにMkDocsがない場合はPATH上のMkDocsのPythonも探します。必要なら環境変数 `GLOSSARY_MKDOCS_PYTHON` に利用するPython実行ファイルを指定してください。

プレビューは127.0.0.1の空きポートで起動します。起動済みなら同じサーバーを再利用します。エディターをCtrl+Cで終了すると、エディターが起動したMkDocsも終了します。他のサーバーやタブを停止することはありません。起動に失敗したときは新しいタブに理由を表示し、ログは `data/mkdocs-preview.log` に残します。

## 画像

個別編集では「説明画像」、表形式では下の「説明画像 ○枚・編集」から操作します。

- `docs/images/` の画像を一覧からファイル名で選べます。「一覧を更新」で後から置いた画像も読み込めます。取り込み済みの `editor/assets/` の画像も含み、同名の場合は `docs/images/` を優先します。
- 「PCから画像を取り込む」では複数ファイルを選べます。元のファイル名を使い、同名で内容が異なる場合だけ識別子を付けます。
- ↑↓で並び替え、「外す」でその用語から取り外せます。画像ファイル自体は削除しません。
- 指定順に横並びで出力します。幅は各150px。JPG・PNG・GIF・WebP、1ファイル12MBまでです。
- PCから取り込んだ画像は `editor/assets/` へ保存し、出力時に `docs/images/` へ反映します。以前のハッシュ名の画像も使えます。

## 保存とバックアップ

- 正式原稿は `data/store.json`。画像を含めた保全には `editor/` と `docs/images/` が必要です。別PCへはリポジトリ全体をコピーしてください。
- `data/history/` に保存前の原稿を直近20回分残します。「バックアップ」から現在の入力を含むJSONもダウンロードできます。JSONには画像ファイルは含みません。
- 出力前の `docs/index.md` と出力時の原稿は `data/site-backups/` に退避します。
- 別タブとの保存競合では上書きを止めます。入力をバックアップしてから再読み込みしてください。
- 原稿を戻す場合はエディターを終了し、現在の原稿を退避してから履歴JSONを `data/store.json` にコピーします。

元Excel・従来スクリプト・ワークスペースの両試作版とは相互に同期しません。`run_make.bat` はエディター原稿からの出力専用です。

用語の削除・画面からのバックアップ読み込みは未実装です。
