## 用語集の編集

`start_editor.bat` で専用エディターを起動します。項目の個別編集と表形式を切り替えながら編集できます。Officeを解約したのでExcelは不要になりました。編集原稿は「サイト用に出力」でmdに出力されます。「MkDocsプレビュー」で出力済みサイトを別タブで確認できます。

操作と保存先は [エディターの説明](editor/README.md) を参照してください。
