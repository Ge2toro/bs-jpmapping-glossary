## 用語集の編集

`start_editor.bat` で専用エディターを起動します。原案の個別編集と表形式を切り替えながら、同じ原稿を編集できます。Officeは不要です。編集原稿は「サイト用に出力」または `run_make.bat` で生成します。「MkDocsプレビュー」で出力済みサイトを別タブで確認でき、pushは手動で行います。

操作と保存先は [エディターの説明](editor/README.md) を参照してください。
